# Historical documentation snapshots

These assets describe the workflow before consolidation to a single A1-A7 layout. They are retained as historical evidence, not current setup or execution instructions. The old guide builder is stored as text so it cannot accidentally regenerate obsolete documentation as a Python script.

Use [the current workflow](../workflow_diagram.md), [the visual diagram](../workflow_diagram.html), and [the project README](../../README.md) for the supported implementation.

The application only supports `layout_version=2`. Historical run databases and native evidence were not deleted or rewritten. Runs stored with other layout identifiers, including unversioned records, are excluded from loading and listing in the current application. Start a new run to use the supported workflow.
